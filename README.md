# KNOT Study v5 — Study専用更新

このZIPはKNOT Study関連ファイルのみです。ブログ本体のページ・記事・レイアウトは含みません。

## 更新内容
- 教科選択を「理科」「社会」の2教科だけに整理。数学・英語・国語の選択肢は表示しません。
- 教科カードを2列の大きなカードに変更し、スマートフォンでも2列表示。
- 理科・社会それぞれの進捗を円形ゲージとパーセントで表示。
- 問題カード表示を追加。「4択カード」と「単語帳カード（答えをめくる）」を選択可能。
- 単語帳カードでは問題を表示し、「答えを見る」で正解と解説を表示。
- 学習済み問題IDを端末内に保存し、教科別進捗に反映。

## 配置先
リポジトリの同じパスに上書きしてください。
- `src/pages/study.astro`
- `src/pages/study/solve.astro`
- `src/data/study-questions.json`
- `public/study/manifest.webmanifest`
- `public/study/icon.svg`
- `public/study/sw.js`

## 注意
- 問題データは理科460問・社会460問の計920レコードです。問題の質・重複の精査は別途継続が必要です。
- 進捗はこの端末・ブラウザに保存されます。以前のバージョンで解いた履歴は自動で全件移行されない場合があります。
- Astroビルドおよび実機ブラウザテストは未実施です。
