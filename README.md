# KNOT

**自分の「好き」と「学び」をつなぐ場所。**

KNOTは、ブログと学習ツールをまとめた個人Webサイトです。

## 🌐 Website

https://knotspace.github.io/

## 📝 Blog

読んだ本、勉強、日常で興味を持ったことなどを記録しています。

- 記事一覧・記事詳細
- 新着記事をトップページに表示
- プロフィール・ブックマーク

## 📚 KNOT Study

ブログとは独立した学習スペースです。中学 **理科・社会** の問題演習に対応しています。

- 理科・社会の2教科
- 学年・難易度・分野で絞り込み
- 10問・20問・全問・苦手問題の演習
- 正誤判定と解説表示
- 解答数・正解数・苦手問題の端末内保存
- ライト／ダークテーマ切り替え

## 🛠️ Development

- Astro 4
- GitHub Pages
- GitHub Actions によるビルド確認

ローカルでの開発：

```bash
npm install
npm run dev
```

本番ビルド：

```bash
npm run build
npm run preview
```
