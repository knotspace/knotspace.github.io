# KNOT Study 更新ファイル

このZIPはKNOT Study専用です。ブログ本体のファイルは含みません。

## 含まれる機能・ファイル
- `/study/` ホーム、演習画面
- 理科・社会の問題データ
- ランダム20問、弱点判定、分野別、模試モード
- 5分モード（5分タイマー）
- 問題ごとのChatGPT / Gemini質問リンク
- 演習画面のライト / ダーク切替（端末に保存）
- PWA manifest、アイコン、Service Worker

## GitHubへの反映
ZIP内のファイルを、リポジトリの同じパスに上書きしてください。Study関連ファイルだけです。

## 注意
- ChatGPT / Geminiボタンは問題文・選択肢・正解・解説を含む質問文を各サービスに渡すリンクです。回答の表示には各サービス側での操作が必要です。
- 毎日のプッシュ通知は、Push配信サーバー・VAPIDキー・購読保存先・定期実行処理の設定が別途必要です。このZIPだけで通知配信が完成するわけではありません。
- 有名人の名言100件は、出典と訳文の確認が必要なため、誤った引用を混ぜないよう今回のZIPには未収録です。
- Astroの本番ビルドおよび実機ブラウザでの動作確認は未実施です。
