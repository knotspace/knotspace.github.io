## 発見・修正した不具合

### 1. ブログ一覧のタブレット横スクロール

- 対象：`/blog/`
- 発生幅：768px
- 原因：カテゴリー絞り込み欄の `width: max-content` が固有幅852pxを要求し、親グリッドの最小幅まで押し広げていた。
- 修正：タブレット幅ではグリッド列を `minmax(0, 1fr)` にし、主要グリッド項目の `min-width: 0` と絞り込み欄の `width: 100%` を指定。ボタンは利用可能幅内で折り返す。
- 修正後：48ルート・3幅・ライト／ダークの再検査に合格。

### 2. Studyの演習ページで発生していたJavaScriptエラー

- 対象：`/study/quiet-practice-7c2e91/`
- 原因：問題バンクJSON全体を配列として扱い、`filter()` を呼び出していた。実際の配列は `questionsData.questions` に格納されていた。
- 修正：JSONオブジェクトから `questions` 配列を取り出して使用するよう修正。
- 修正後：全画面幅で未処理JavaScriptエラーが発生しないことを確認。

### 3. Study内のリンク誤り

- 要点まとめ共通ページの「Studyホーム」「問題演習」「一覧へ戻る」の相対パスを修正。
- 数学・要点まとめの秘密モード・一覧・Studyホームへのパスを修正。
- タイマーからStudyホーム・学習ツールへの相対パスを修正。
- 最終リンク監査では、動的テンプレートURLを誤検出として扱わず、93件の同一オリジンパスを確認。

### 4. Studyナビゲーションの不要な文字列

- `StudyLayout.astro` に混入していた文字列の `\\n` を実際の改行に修正。

### 5. ゲーム用学校データの欠落

- `public/data/game/university/schools/` の `01.json`、`13.json`、`27.json` が0バイトだった。
- 共通の学校データ側にある対応ファイルのGit blobを再利用して復元。
- 修復後、学校データ47ファイルすべてで共通データ側と大学ゲーム側のblobが一致することを確認。

### 6. ブログ品質チェックの誤検出

- ゲーム内に表示する公的な相談窓口の電話番号を、個人の連絡先と誤判定していた。
- `public/one-life` と `public/game/university` の日本語・英語・韓国語・中国語のゲームデータを、既存の青の分岐点と同じ公的窓口データとして明示。
- Blog Quality Patrolの画像・個人情報チェックは成功。
