3. **既存データの品質課題**(`npm run study:validate` の結果。構造エラーは0件):
   - 正解位置の偏り: 選択肢2番目が正解の割合が 過去問バンク56%・基礎網羅58%・公立入試精講61%・演習バンク42%。
   - `study-questions.json` は1,044件中、問題文・選択肢が完全に同一の重複が352件(ユニークは692件)。「ある学習者が『◯◯』について調べている…」型のテンプレートの複製。正答の食い違いは0件。
   - ID重複: `pe-up-001〜014` が `study-foundation.json` と `public-exam-upgrade.json` の両方に、`pastref-*` 4件が `private-past-bank.json` と `private-practice-bank.json` の両方にある。
