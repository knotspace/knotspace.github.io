# 1億2380万分の1

日本の人口1億2,380万人のひとりとして、47都道府県のどこかに生まれ、実在の高校・大学・職業・年収の統計で一度きりの人生を生きる人生シミュレーション。単一HTML。

## 元ネタ
Jin（[@jins__earth](https://x.com/jins__earth)）さんの世界版「[1 in 8 Billion](https://1in8b.life/)」のアイデアをお借りして作った日本版です。

## 公開
GitHub Pages: Settings → Pages → Branch `main` / folder `/ (root)`。

## データの出典
人口動態統計（厚生労働省）／令和2年都道府県別生命表／人口推計2024（総務省）／人口統計資料集2024（社人研）／令和6年賃金構造基本統計調査／家計調査 貯蓄・負債編2024／消費者物価指数（総務省）／労働力調査（総務省）／一般職業紹介状況（厚生労働省）／日経平均株価（年末値）／日本の将来推計人口 令和5年推計（社人研）／Works Report「未来予測2040」（リクルートワークス研究所）／労働市場の未来推計2030（パーソル総合研究所）／国土のグランドデザイン2050（国土交通省）／みんなの高校情報／みんなの大学情報／福岡県立高等学校通学区域規則。統計にない出来事の確率や収入はゲーム上の設定。2027年以降の景気・物価・政策・選挙はシミュレーション（想像）で、登場する陣営は架空です。

## 注意
18歳以上向け。自殺・事故・病気・犯罪などの重い出来事が統計どおりの確率で起こります。
