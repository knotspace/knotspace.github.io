ねえ、みんなのPCにはどんなソフトが入っています？

PCを買ったときって、最初からいろいろなアプリが入っていますよね！でも実は、無料で使える便利なソフトがまだまだたくさんあるんです！？

今回は、自分がPCを使う中で気になったフリーソフトを10個紹介していきます！

ブラウザやファイル管理系から、動画編集、プログラミングまで幅広く選んでみた！中には「これ無料で使えるの！？」って思うようなものもあるかも？

ちなみに、今回紹介するのは主にWindows向けのソフトですよ。気になったものがあったら、ぜひチェックしてみてください！

それではいってみよう！！

## 1. Brave｜広告をブロックできるブラウザ

<figure class="app-icon-figure"><img src="https://cdn.simpleicons.org/brave" alt="Brave の公式サイトアイコン" width="112" height="112" loading="lazy" decoding="async" /><figcaption><a href="https://brave.com/ja/" target="_blank" rel="noopener noreferrer">Brave 公式配布元</a>のサイトアイコン</figcaption></figure>

まず最初は「Brave」！

これはGoogle Chromeなどと同じWebブラウザなんですけど、自分的にはかなりおすすめしたいソフトなんですよね！

Braveの大きな特徴は、広告やトラッカーをブロックする機能が最初から入っていますこと！

普通にWebサイトを見ていると、広告がたくさん表示されることがありますよね？場合によっては、画面を覆うような広告が出てきて邪魔だなって思うこともありますね？

Braveなら、そういう広告を標準機能でブロックできるんです！

しかも、Chromeと同じChromiumをベースにしていますから、Chromeを使ってた人でも比較的移行しやすい！

ブラウザを変えてみたい人や、普段のネット閲覧を少しでも快適にしたい人は、ぜひ試してみてください！

**おすすめポイント**

- 広告・トラッカーのブロック機能
- Chromeに近い操作感
- 拡張機能にも対応

公式サイト：[https://brave.com/ja/](https://brave.com/ja/)

## 2. QuickLook｜スペースキーだけでファイルをプレビュー！

<figure class="app-icon-figure"><img src="https://raw.githubusercontent.com/QL-Win/QuickLook/master/Build/Assets/Square150x150Logo.scale-100.png" alt="QuickLook の公式アプリアイコン" width="112" height="112" loading="lazy" decoding="async" /><figcaption><a href="https://github.com/QL-Win/QuickLook" target="_blank" rel="noopener noreferrer">QuickLook 公式配布元</a>の公式アプリアイコン</figcaption></figure>

次は「QuickLook」！

正直、今回紹介する中でもかなり便利だと思っていますソフトなんですよね！

Windowsでファイルの中身を確認したいとき、いちいちファイルを開く必要がありますよね？

例えば画像を確認したいなら、画像ファイルをダブルクリックして、アプリが起動して……っていう作業が必要になりますね。少し手間ですよね？

でもQuickLookを使えば、ファイルを選択してスペースキーを押すだけ！

それだけでファイルの中身をプレビューできますんです！

画像やPDFなどを確認するときに特に便利で、ファイルを何個も確認するときは本当に作業が楽になる！

Macには似たようなプレビュー機能が標準であるけど、Windowsでもこれができるのはうれしくありませんか？

一度使うと、今までなんでわざわざファイルを開いてたんだろう？って思うかも（笑）！

**おすすめポイント**

- スペースキーで簡単にプレビュー
- ファイルをいちいち開かなくていい
- ファイル整理がかなり楽になる

公式ページ：[https://github.com/QL-Win/QuickLook](https://github.com/QL-Win/QuickLook)

## 3. AviUtl｜無料なのに自由度が高い動画編集ソフト

3つ目は「AviUtl」！

動画編集をしています人なら、一度は聞いたことがあるかもしれないソフトですよね？

AviUtlは昔から使われてる動画編集ソフトで、最大の魅力は拡張性の高さ！

プラグインなどを追加することで、いろんな編集機能が使えるようになります！

テロップを入れたり、映像にエフェクトを付けたり、細かい調整をしたりと、かなり自由度の高い編集ができる！

しかも無料！！

ただし、最初から何でもできるわけじゃなくて、プラグインの導入や設定が必要になることもあるんですよね。ここは少し初心者泣かせかも（笑）。

最近の動画編集ソフトと比べると、導入に手間がかかる部分もあるけど、自分好みの編集環境を作りたい人には面白いソフトだと思います！

**おすすめポイント**

- 無料で動画編集ができる
- プラグインで機能を拡張できる
- 細かい編集にこだわれる

公式サイト：[https://spring-fragrance.mints.ne.jp/aviutl/](https://spring-fragrance.mints.ne.jp/aviutl/)

キャラクターのセリフを入力したり、音声を設定したり、字幕を付けたりっていう作業をまとめてできます！

## 5. Visual Studio Code｜プログラミングを始めるならこれ！

<figure class="app-icon-figure"><img src="https://cdn.simpleicons.org/visualstudiocode" alt="Visual Studio Code の公式サイトアイコン" width="112" height="112" loading="lazy" decoding="async" /><figcaption><a href="https://code.visualstudio.com/" target="_blank" rel="noopener noreferrer">Visual Studio Code 公式配布元</a>のサイトアイコン</figcaption></figure>

5つ目は「Visual Studio Code」！

通称VS Codeって呼ばれてる、Microsoftが提供していますコードエディターです！

プログラミングやWebサイト制作をしています人には定番のソフトだと思います！

実際にKNOTのサイトを作るときにも、VS Codeを使っていますんだ！Astroのファイルを編集したり、HTMLやCSSを直したりするときに、コードの色分けや入力補助があるのはかなり助かる！最初は画面に並ぶファイルや記号が多くて戸惑ったけど、少しずつ慣れてきたよ。

プログラムを書くと、色分けして表示してくれたり、入力を補助してくれたりするんですよね！

さらに、拡張機能を追加すれば、自分の使いやすい環境にカスタマイズすることもできる！

HTMLやCSS、JavaScriptなどを勉強してみたい人にもおすすめ！

最初は少し難しそうに見えるけど、プログラミングに興味があるなら、ぜひ触ってみてほしい！

**おすすめポイント**

- 無料で使えるコードエディター
- 多くのプログラミング言語に対応
- 拡張機能が豊富

公式サイト：[https://code.visualstudio.com/](https://code.visualstudio.com/)

## 7. Everything｜PC内のファイルを爆速検索！

PCを長く使っていますと、ファイルがどんどん増えていくよね？

そんなときに便利なのがEverything！

検索欄にファイル名を入力するだけで、該当するファイルをすばやく探してくれるんだ！

Windows標準の検索機能でなかなか見つからないときにも役立つよ！

派手な機能があるわけじゃないけど、こういうシンプルなソフトこそ意外と長く使うんですよね！

**おすすめポイント**

- ファイル名から高速検索
- 操作がシンプル
- ファイルが多いPCほど便利

公式サイト：[https://www.voidtools.com/ja-jp/](https://www.voidtools.com/ja-jp/)

## まとめ｜無料でもPCはここまで便利になる！

今回は、PCに入れておきたいおすすめのフリーソフトを10個紹介してみたよ！

改めてまとめると、

1. Brave：広告ブロック機能付きブラウザ
2. QuickLook：スペースキーでファイルをプレビュー
3. AviUtl：自由度の高い動画編集ソフト
4. YMM4：ゆっくり実況・解説動画の制作
5. Visual Studio Code：プログラミング・Web制作
6. Microsoft PowerToys：Windowsの便利機能集
7. Everything：高速ファイル検索
8. 7-Zip：圧縮・解凍
9. ShareX：スクリーンショット・画面録画
10. VLC media player：動画・音楽の再生

こうして見ると、無料でもかなり便利なソフトがそろってるよね！

もちろん、全部を一度にインストールする必要はないよ！自分が使いそうなものから試してみるのがおすすめ！

自分的には、QuickLookとEverythingは一度使ってみてほしい！派手さはないけど、普段のPC操作がかなり快適になると思います！

あと、これはめちゃくちゃ大事なんですけど、ソフトをダウンロードするときは、なるべく公式サイトや公式配布ページを使ってね！よくわからないサイトからダウンロードするのは避けた方がいいよ！
