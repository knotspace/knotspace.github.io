「自分で考えたアプリやソフトを、もっと本格的に開発してみたい」。そんな人に関係する公募が、2026年11月9日に始まりました。情報処理推進機構（IPA）が、2027年度の「未踏IT人材発掘・育成事業」の募集を開始しています。

この事業は、独創的なアイデアや技術を持つ個人・グループを採択し、プロジェクトマネージャー（PM）の指導・助言を受けながら開発に取り組むものです。単にプログラミングを学ぶ講座というより、自分で提案したプロジェクトを実際に形にしていく機会です。

## まず、いつまでに何をすればいい？

今回の募集では、最初の「応募エントリー」と、提案書類を提出する本申請の締切が別になっています。

| 手続き | 受付期間・締切 |
| --- | --- |
| 応募エントリー（事前申請） | 2026年11月9日〜2027年3月8日 11:59 |
| 公募申請の締切 | 2027年3月11日 16:59 |
| 二次審査（ヒアリング） | 2027年4月中旬予定 |
| オンライン公募説明会 | 2026年12月4日 18:30〜19:30 |
| 説明会の申込締切 | 2026年11月30日 17:00 |

特に気を付けたいのが、事前エントリーを済ませただけでは応募完了にならないことです。IPAの案内では、Google Formsへの応募情報登録と、Google Driveへの提案資料アップロードの両方が必要とされています。どちらか一方だけでは審査対象になりません。

## 応募できるのはどんな人？

2027年4月1日時点で25歳未満であることが条件の一つです。個人、または個人で構成するグループとして応募します。法人格のある組織としての提案は受け付けていません。

ほかにも、過去の採択歴やスーパークリエータ認定、ほかの未踏事業との期間重複などの条件があります。年齢だけで判断せず、公式の「提案者の要件」を一つずつ確認してください。

募集テーマは原則として限定されていません。ソフトウェアに関係するアイデアで、独自性・革新性があり、将来の社会に影響を与える可能性があるプロジェクトが対象です。完成した大規模サービスだけが対象というわけではありませんが、「何を解決したいのか」「なぜ今までの方法では足りないのか」「自分はどう実現するのか」を説明できることが重要になります。

## 応募前に準備したいこと

いきなり申請フォームを埋めるより、まずは提案の中身を整理しておくと進めやすくなります。

1. **解決したい課題を一文にする。** 誰が、どんな場面で困っているのかを具体化します。
2. **既存サービスを調べる。** 似たものがある場合は、何が違うのかを説明できるようにします。
3. **最小の試作品を作る。** 画面だけでも動くデモでも、アイデアを他人に伝えられる形にします。
4. **実現方法を調べる。** 使用する技術、必要なデータ、開発上の難所を洗い出します。
5. **PMのメッセージを読む。** 2027年度は7名のPMが担当します。各PMが期待する提案の方向性を確認して、自分のテーマと合うか考えます。

提案書では、アイデアの面白さだけでなく、開発期間中に何を作り、どこまで確かめるのかを具体的に書くと、計画の伝わり方が変わります。

## 未成年の場合は保護者の確認も必要

IPAのページでは、未成年の応募者について、二次審査（ヒアリング）の際に保護者からの承諾書を提出するよう案内されています。応募する本人だけで手続きを進められるとは限らないため、早めに保護者へ相談しておきましょう。

また、採択後の契約に際しては、所属組織からの承諾書が必要になる場合があります。学校などに所属している人は、公募要領の説明も確認してください。
