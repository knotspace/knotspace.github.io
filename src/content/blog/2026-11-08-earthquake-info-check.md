地震が起きたとき、まずスマホでニュースやSNSを確認する人は多いと思います。

実際、2026年11月8日の日本向けGoogleトレンドでは、地震に関する検索語が急上昇ワードとして表示されていました。こういうときに気になるのが、「SNSで見た情報は本当なの？」「どこを見れば正確な震度が分かるの？」ということ。

今回は、地震の速報やSNSの投稿を確認するときに知っておきたいポイントを、気象庁や政府の公開資料をもとに整理します。

※この記事は情報の確認方法をまとめたものです。実際に揺れを感じた場合は、まず身の安全を確保し、自治体・消防・警察などの指示に従ってください。

## 1. 最初に確認するのは「発信元」

SNSでは、地震直後にさまざまな情報が流れてきます。現地の写真や動画が役立つ場合もありますが、投稿だけでは正確性を判断できないこともあります。

まず確認したいのは、投稿の内容よりも**誰が発信しているか**です。

- 気象庁などの国の機関
- 都道府県・市区町村などの自治体
- 消防・警察などの公的機関
- 鉄道会社・電力会社など、サービスを運営する事業者

避難所の開設状況や交通機関の運行情報などは、まとめ投稿だけで判断せず、該当する自治体や事業者の公式発表を確認しましょう。

政府広報オンラインも、災害時には自治体など複数の信頼できる情報源を確認し、SNSの情報をそのまま拡散しないよう呼びかけています。

## 2. 「震度」と「マグニチュード」は別の数字

ニュースでよく見る「震度」と「マグニチュード」。似たような数字に見えますが、意味は違います。

| 用語 | 何を表す？ |
| --- | --- |
| 震度 | ある場所での揺れの強さ |
| マグニチュード | 地震そのものの規模 |

同じ地震でも、場所によって観測される震度は異なります。地盤や地形、建物の階数などによって、体感する揺れにも差が出ることがあります。

そのため、「マグニチュードが大きいから、自分の地域も必ず同じ強さで揺れる」と考えるのは正確ではありません。自分がいる場所の情報を確認することが大切です。

出典：気象庁「震度・マグニチュード・地震情報について」

## 3. 地震情報は、発生後に段階的に更新される

地震の情報は、最初の速報だけで完結するわけではありません。気象庁は、新しい観測データが入るにつれて、情報を順次発表しています。

| 情報の種類 | 主な内容 |
| --- | --- |
| 震度速報 | 震度3以上を観測した地域名など |
| 震源に関する情報 | 震源の場所や規模など |
| 震源・震度情報 | 震源、マグニチュード、観測地点ごとの震度など |
| 推計震度分布図 | 観測データをもとに推計した震度の分布 |

気象庁によると、震度3以上の地震では、地震発生から約1分半後を目安に震度速報が発表され、その後、震源や各地の震度などを含む情報が発表されます。

つまり、最初に見た速報と、少し時間がたってからの情報で内容が変わることもあります。投稿時刻や更新時刻を確認し、古い情報を最新情報として扱わないようにしましょう。

## 4. SNSで見かけた情報を拡散する前のチェックリスト

災害時は、善意で共有した投稿が、結果として誤情報を広げてしまうこともあります。投稿を見たら、次の5点を確認してみてください。

1. **発信元は明らか？**  
   公的機関や当事者の公式発表か、出どころが分からない投稿かを確認する。
2. **いつの情報？**  
   投稿日時だけでなく、元の出来事がいつ起きたのかも見る。
3. **場所は一致している？**  
   別の地域や過去の災害の写真・動画が使われていないか確認する。
4. **ほかの情報源でも確認できる？**  
   自治体、気象庁、報道機関など複数の情報を比べる。
5. **今、拡散する必要がある？**  
   真偽が確認できない場合は、共有せずに保留する。

特に注意したいのは、救助要請や避難所の場所、支援物資の募集など、人の行動に直接影響する情報です。確認できない投稿を広めると、救助や復旧の妨げになる可能性があります。

防災庁の令和8年版防災白書でも、SNSのデマや偽情報が救助活動や復旧の妨げになり得ること、政府や自治体の公式アカウントなど確かな情報源を確保することの重要性が説明されています。

## 5. いざというときのために、確認先を先に登録しておく

地震が起きてから情報源を探すと、焦ってしまうかもしれません。普段のうちに、次のページをブックマークしておくと便利です。

- [気象庁：地震情報](https://www.jma.go.jp/bosai/map.html#contents=earthquake)
- [気象庁：地震情報について](https://www.jma.go.jp/jma/kishou/know/jishin/joho/seisinfo.html)
- [消防庁：災害情報](https://www.fdma.go.jp/disaster)
- [政府広報オンライン：防災特集・発災時の行動](https://www.gov-online.go.jp/tokusyu/bousai/disaster.html)

また、家族や身近な人と、災害時の連絡方法や集合場所を話し合っておくことも大切です。情報を集めるだけでなく、実際にどう行動するかを決めておくと、いざというときに役立ちます。

## まとめ：速さだけでなく、確かさも大切に

地震が起きた直後は、SNSで情報をすぐに見つけられる一方、古い情報や誤った情報も混ざる可能性があります。

大切なのは、発信元・日時・場所を確認し、気象庁や自治体などの公式情報と照らし合わせること。そして、確かめられない情報は安易に拡散しないことです。

普段から公式の確認先をブックマークしておくだけでも、いざというときの行動につながります。まずは一つ、よく使う確認先を保存しておくところから始めてみてください。
